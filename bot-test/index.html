Church Website Assistant

This is a private test page for the Providence Community Church chat assistant. Click the green chat button in the bottom-right corner to try it.

Things to try:

  • What time is your Sunday service?
  • Where are you located / do you have kids' ministry?
  • Has the pastor preached about anxiety, marriage, or suffering?
  • An off-topic request (it should decline), or a sensitive topic (it should hand off to a human).
How it embeds: one line on any page — <script src="/chat-widget.js" defer></script>. Nothing else is required; the widget injects its own button and panel. When we move it to the church site, this same file goes there.
